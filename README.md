# Clothes E-commerce Project

A responsive web application project for an apparel or clothing store. This project features a clean user interface with a custom-styled navigation bar and footer.

## 🚀 Features
- **Responsive Layout:** Built to work on all device sizes (mobile, tablet, and desktop).
- **Custom Branding:** Includes a uniquely styled "aqua" themed navigation bar.
- **Fixed Footer:** A professionally styled dark footer with navigation links.
- **Custom Buttons:** Specialized styling for action buttons (e.g., `.btn3`).

## 🛠️ Technologies Used
- **Bootstrap v4.4.1:** Used as the primary CSS framework for the grid system and core components.
- **Custom CSS:** Specialized styles located in `clothes.css` for project-specific branding and layout adjustments.
